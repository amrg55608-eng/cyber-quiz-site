# Cyber Security Quiz

Files: index.html, style.css, script.js, data.js

## Publish on GitHub Pages
1. Create a new repository on GitHub (Public).
2. Upload all files in this folder (index.html must be at the repository root).
3. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
4. After a minute your link appears: https://USERNAME.github.io/REPO-NAME/
